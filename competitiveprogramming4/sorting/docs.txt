a. Inversion Index
Given a list of numbers, count the minimum number of bubble sort swaps.
Example:
{3, 2, 1, 4}
need 3 -> swap (3, 2), swap (3, 1)
{2, 1, 3, 4}
need 2 -> swap (2, 1)
=> we have 3 times need to sort using bubble sort
// Build algorithm
devide 2 partitions:
{3, 2} {1, 4}
if length of each partition is <= 2:
    length = 2: return 1 if a < b, 0 otherwise
    length = 1: return 0
{2, 3} {1, 4}
merge1 = merge({3, 2}) = {2, 3} res++
merge2 = merge({1, 4}) = {1, 4}
find the largest number in merge2 (cnt = i+1) that smaller than merge1[0] res += len(merge1) * cnt

b. Sorting in Linear times
Given an (unsorted) array of n elements, can we sort them in O(n) time

b1. O(n+k) Counting sort
If the array A contains n integers with small range [L...R], we can use the Counting Sort algorithm.
A = {2a, 5, 2b, 2c, 3a, 3b}
1. Prepaer a frequency array f with size k = R-L+1 and initialize f with zeroes
e.g: L = 2, R = 5 and k = 4
2. Update array
3. Compute the prefix sums of each i: pre[i] = pre[i-1] + f[i]
4. Build result(n): res[pre[arr[i]-L]-1] = arr[i]
                    pre[arr[i]-L]--
